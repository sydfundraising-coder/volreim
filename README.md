# VolReim

Volunteer expense reimbursement and supplier invoice approval for BAPS Swaminarayan Sanstha Australia.

- Front end: static web app (GitHub Pages)
- Back end: Supabase (Postgres with row-level security, email sign-in, storage)
- Phase 1: submission, two-step approval, Mandir Centre AP check, SharePoint storage, email to Central AP
- Phase 2: posting to Acumatica

This repository holds application code only. No keys other than the public Supabase anon key, and no approver, volunteer or claim data, are stored here.
